# RiftEye data

Card data for **RiftEye**, a browser extension that names the cards on Twitch and YouTube Riftbound streams.

- **Releases** (`cards-<generation>`): the card index the extension downloads when a new set comes out. `latest.json`
  lists the current files and their SHA-256 checksums.
